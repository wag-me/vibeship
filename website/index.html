Your Claude Code agents, working on a spaceship.(ﾉ◕ヮ◕)ﾉ*:･ﾟ✧ 出航！

Vibeship is a mod for Claude Code. Every session becomes a crew member in a small 3D ship: it walks to its console when it reads and writes, sleeps when it's idle, and asks you on the bridge before running something risky.

› /plugin marketplace add wag-me/vibeship
01Manifestマニフェスト

What's on board

  • crewOne character per session. It reads, writes, runs commands and searches the web, and you see it happen.
  • chatTalk to any agent from the window. Stop or close it, run slash commands with suggestions. History comes back from the transcript.
  • alertsPermission requests turn the ship red. Approve or deny there; after ~30 s the question goes back to the terminal.
  • dronesSubagents arrive by drone. They roam the room while the task runs and fly back with the result.
  • activityFiles written with +/− lines, commands, failures. Plus a read-only file browser that hides secrets and node_modules.
  • serversDev servers your agents start get an Open link. Ones left running after a session ends are flagged.
  • statsTokens, sessions, tools, projects and models. 7, 14 or 30 days, read from local transcripts.
  • decksBridge, Engine room, Greenhouse. Edit mode to move, rotate, add and remove furniture.

03Installインストール

Boarding procedure

Requires Claude Code ≥ 2.1.287, Node.js and a WebGL browser. Tested on Windows; macOS is written but untested.

  1. Install the mod

    Inside Claude Code, any project:

    › /plugin marketplace add wag-me/vibeship › /plugin install vibeship@vibeship

  2. Restart, then launch

    Starts the local server and opens the window.

    › /vibeship

    New sessions show up by themselves. For one already running, type /vibeship in it.

  3. Update

    The window tells you when there's a new version.

    $ claude plugin marketplace update vibeship $ claude plugin update vibeship@vibeship

    Just trying it? claude --plugin-dir /path/to/vibeship loads it for one session.

05Securityセキュリティ
  • Local only. The server listens on 127.0.0.1.
  • Token. Chat, permissions, new agents and stats need a random token that only the window opened by /vibeship gets.
  • Nothing leaves your machine. Stats come from local transcripts. The update check only downloads plugin.json; turn it off with VIBESHIP_NO_UPDATE_CHECK=1.
  • Not sandboxed. Same access as Claude Code. Only install mods you trust.
